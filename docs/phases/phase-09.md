# Phase 09 — Interview Prep

## 1. 本阶段目标

本阶段结束后，我能够：

> 把 9 个 Phase 的技术积累转化为面试表现：30s/1min/3min 讲稿、高频题库、两轮模拟面试，并在不翻文档的情况下讲清项目。

---

## 2. 为什么学习这个？

8 个 Phase 的积累是"库存"，面试是"变现"。技术再好，讲不出来等于没有。面试表达有自己的规律：**讲故事而不是背名词、用数字而不是形容词、承认边界而不是装懂**。本阶段把这三条规律落到你的项目上。

---

## 3. 核心概念

### 3.1 面试表达的三个框架

**框架一：问题 → 方案 → 数据**（讲每个技术决策的标准句式）

> "之前的问题是 X（正则提取 JSON 脆弱）→ 我的方案是 Y（JSON mode + zod + 重试）→ 数据证明 Z（单测 12/12，真实调用零重试）。"

对比反面教材："我用了 zod 做校验"——没有问题和数据，技术只是名词堆砌。

**框架二：数字是锚点，句子自己组织**

背数字不背句子：48 个测试原样通过、8/8 vs 1/8、4/6→6/6、4.33 分、11 次→2 次。数字让对方记住你，句子的自然程度让对方相信你。

**框架三：主动承认边界**

"我没上向量库因为……""我的记忆严格说是长上下文不是用户画像""checkpointing 我理解但没启用因为……"——**承认边界的人可信，装懂的人会被追问击穿**。你的项目里有完整的克制清单，这是别人没有的资产。

### 3.2 答题红线（模拟面试重点检查）

1. ❌ 技术名词堆砌不解释（"我用了 RAG"——哪个环节是你做的？）
2. ❌ 数字含糊（"大概几十个测试"——53 个就是 53 个）
3. ❌ 被追问就慌（"这个……我记得是……"——不确定就说不确定，然后给出排查思路）
4. ❌ 讲功能不讲故事（"做了个聊天功能"——问题是什么？）
5. ❌ 贬低自己的踩坑（"我犯了个低级错误"——错误+定位过程+修复 = 最好的素材）

## 5. 模拟面试设计

### 第 1 轮：基础关（30 分钟）

目标：考察"能不能不看文档讲清楚"。5 题：

1. 30 秒介绍项目（讲稿训练）
2. Agent Loop 的终止条件？max_iter 为什么是 5？
3. Function Calling 里模型和代码各自做什么？
4. State 存哪？为什么不上 Redis？
5. eval 第一轮发现了什么？怎么修的？

通过标准：每题 1-2 分钟讲完，无"我记得/大概是"。

### 第 2 轮：深挖关（30 分钟）

目标：根据第 1 轮的回答追击，考察"是不是真的懂"。追击方向示例：

- 你说"双实例"是因为冲突——**冲突的报错长什么样？你怎么定位到根因的？**
- 你说"强制 grounding"——**如果模型就是不肯调用工具呢？tool_choice 的取值有哪些？**
- 你说"阈值 0.48"——**0.47 和 0.49 差在哪里？阈值变了会怎样？**
- 你说"judge 均分 4.33"——**judge 自己打分会有偏差吗？怎么验证 judge 可靠？**

通过标准：追问三层不崩。

### 通过后的收尾

- 把第 1 轮的口头回答录下来回听，对照讲稿改措辞
- 每次面试前 15 分钟过一遍"数字速记卡"

## 6. 高频追问 TOP 10（面试官视角预演）

1. "为什么用 LangChain？你只用了 ChatOpenAI 和消息类"→ 为 LangGraph 铺路 + 生态一致 + 敢说"其实原生 SDK 也行"
2. "为什么用 LangGraph？"→ 手写过了才有资格说"框架替我做了什么"
3. "为什么不上向量库/Redis？"→ 规模判断 + 演进路径
4. "你的记忆是 Memory 吗？"→ 承认是长上下文 + 说出真正的 Memory 该怎么做
5. "json_object 和 tool_choice 冲突？具体报错是什么？"→ "reading 'message'" + 裸 API 隔离法
6. "150 元案例住宿 0 元为什么放行？"→ 规则校验的边界 + 现实层校验
7. "怎么评估 Agent？"→ 三层体系 + 第一轮 2/6 失败的迭代故事
8. "token 成本多少？"→ eval 两批 ~117k token + 四层优化
9. "max_iter 为什么是 5 不是 10？"→ 保险丝不是常态出口 + 实测轮次分布（北京 3 轮/三亚 4 轮）
10. "如果知识库 10 万条怎么办？"→ 向量库 + 混合检索 + rerank
